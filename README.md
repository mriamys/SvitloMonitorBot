# Svitlo Monitor Bot ⚡💡

Асинхронний Telegram-бот для автоматизованого моніторингу графіків відключень електроенергії, сповіщень користувачів, груп та каналів.

## Ключові можливості

### 👤 Для користувачів
- **Інтелектуальні сповіщення**:
  - `Pre-alert`: завчасне попередження за 5, 15, 30 або 60 хвилин до відключення.
  - `Post-alert`: сповіщення про відновлення електропостачання.
  - `Moment-alert`: повідомлення точно в момент перемикання за графіком.
  - `Update-alert`: сповіщення про термінові зміни в графіках протягом дня.
- **Ранкове зведення**: персоналізований розклад о 06:00.
- **Режими відображення**: темний («коли темно») або зелений («коли світло»).
- **Аналітика**: статистика тривалості відключень за останні 7 днів.

### 📢 Для груп та каналів
- **Швидка інтеграція**: команда `/addtogroup` з автоматичним генератором посилань.
- **Адмін-панель у ПП**: керування налаштуваннями каналів через Deep Linking.
- **Синхронізація**: індивідуальні таймери та типи сповіщень для кожної групи.

### 👨‍💻 Адміністрування
- **Telegram Адмін-панель**: керування розсилками та перегляд метрик бота.
- **Система тікетів**: вбудований зворотний зв'язок з користувачами.
- **Автобекапи**: щоденне створення та надсилання резервної копії бази даних.

## Технічна архітектура

- **Dual-API Failover**: автоматичне перемикання між основним (Primary API) та резервним (Backup API) джерелами даних при збоях.
- **Розумний планувальник**: APScheduler оптимізує черги розсилок без блокування обробки оновлень.
- **Асинхронна база даних**: зберігання користувачів, черг та історії у SQLite через `aiosqlite`.

## Стек технологій

- Python 3.11+
- aiogram 3.x
- aiosqlite
- APScheduler
- aiohttp
- Docker Compose

## Розгортання та запуск

### Запуск через Docker Compose (рекомендовано)

1. Створіть файл `.env`:
   ```env
   BOT_TOKEN=ваш_токен_від_BotFather
   ADMIN_IDS=id_адміна_1,id_адміна_2
   PRIMARY_API_URL=https://основне_джерело_даних
   BACKUP_API_URL=https://резервне_джерело_даних
   UPDATE_INTERVAL=300
   FAILOVER_TIMEOUT=10
   ```

2. Запустіть контейнер:
   ```bash
   docker compose up -d --build
   ```

### Локальний запуск

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python main.py
```
